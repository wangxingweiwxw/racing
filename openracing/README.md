# 开放街道 openracing

访问根地址会默认进入 `/openracing/`，也可从赛道主菜单点击「开放街道」。页面右上角「赛道」打开上海 F1 / 纽北选择面板，选择后直接进入车型与配色设置。赛道仅保留计时赛和自由驾驶，无 AI 对手；默认完整单圈，界面不显示单圈选项。
共享依赖和车型代码由 Vite 多入口构建输出，两个模式按需加载各自场景。

## 玩法与操作

从南京东路出发，探索外滩和陆家嘴，完成拍照点、计时赛和美食探索；漂移、滞空、贴墙、擦车积累连击。
车流遵循路网和信号灯，碰撞会打断连击。落水后自动回到安全点，也可主动复位。

两岸各有三条青色跨江路线。沿地面箭头加速驶向跳台，距岸约 100 m 内的引导区快速补气（兼容 8 m 以下的提前悬浮），
离台后在通道内以至少约 43 km/h 朝对岸飞行即可触发「跨江辅助」。辅助托举到约 9 m 并补充向前推力，
松开起飞键也能继续过江，抵达对岸后退出；按刹车可主动退出，方向键仍可转向。
辅助仍消耗气量，气量耗尽或远离通道会失效。跳台拓宽为 18 m，平台入口坡拓宽为 20 m，
岸边栏杆为跳台留出了开口。低油量、54 km/h 初速、约 75 m 助跑的多种操作已作双向回归验证。

江面有三艘三层观光游轮，以约 10 m/s 沿闭合航线往返，转弯连续，带舷窗、上层观景座椅、
栏杆、救生圈、船名和尾流；小地图以金色标记显示船位。游轮有动态碰撞体，不会像贴图一样被直接穿过。

| 输入 | 功能 |
| --- | --- |
| W / S | 地面油门 / 制动倒车；空中微推 / 减速 |
| A / D | 地面转向；空中转向和速度方向辅助 |
| E（或 J） | 点按起跳，持续按住定高悬浮；松开下降 |
| Shift | 后部冷气推进，地面与空中均可使用 |
| X | 停车开蝶翼门/尾翼展车；离地足够高时单次横滚 |
| F | 切换吸附爬楼；全油门持续上爬延缓过热，慢爬/倒挂约 7 秒过热 |
| 空格 | 手刹漂移；空中配合 A / D 手动横滚 |
| I / K | 空中手动俯仰；松开后自动稳定 |
| R / 手机「脱困」 | 关闭吸附，回到最近的安全路面 |
| C / M / H（Esc） | 切换相机 / 静音 / 暂停帮助 |

手机提供两侧驾驶按钮，可同时按加速与起飞；失去焦点或暂停时释放按键，避免持续加速。
手柄左摇杆转向/俯仰，RT/LT 油门/制动，A 悬浮，RB 推进，B 展车/翻滚，X 手刹，Y 吸附，Back 复位，Start 换视角。

## 建筑碰撞与近景细节

参考 `6258.mp4` 的街道驾驶镜头，追尾视角保持世界地平线；回弹和倒车不再让镜头突然掉头。
旧镜头的前方观察点会进入建筑，导致避障把相机拉进墙内；现在观察点留在车旁，使用球形连续检查，
遇到后方墙角选择较高或侧面视角，障碍离开后平滑拉远。撞击晃动减弱，并限制连续碰撞特效频率。
普通地面驾驶增加车头/车尾的建筑碰撞范围，轻微回弹保留沿墙滑行；顶住墙时仍可低速转向和倒车。
「脱困」回到有整车净空的安全点并关闭吸附，避免只原地抬高后又贴回墙面。主动风扇爬墙玩法保留。

NPC 的轿车、SUV、出租车、厢式车、公交车增加车窗立柱、后视镜、门缝、轮毂、格栅、灯组与牌照细节。
车漆和玻璃/轮胎分开实例化，95 m 外使用轻量轮廓，420 m 外不提交车辆实例。
街道加入路缘、排水槽、盲道色带、长椅、花池、候车棚、底商橱窗与雨棚、路面颗粒和层次树冠；
实例化建筑的样式/颜色/随机种子使用平面插值，避免立面色块出现随机条纹和闪烁。
这些是程序化近景细节，不是对视频城市的逐栋复制。

`tools/openracing/camera.test.ts` 在 30/60/120 Hz 检查墙角避障、回弹、倒车、车头净空及安全脱困。
`tools/openracing/detail.test.ts` 检查 NPC 几何边界/面数和街景批次数。
`tools/check-street-collisions.cjs` 实际渲染撞建筑、倒车、脱困、手机画面和街景车流。

## 模型与腾空

### 爬楼飞跃和喷气制动

- 开启 F / 手机「吸附」，朝楼面加速即可爬墙；持续加速上爬时降低风扇积热速度，允许攀爬高楼。停留或慢爬仍会过热，冷却规则保留。
- 爬到屋顶可以刹车停下，也可以继续加速驶出边缘：自动关闭吸附，轻跃离开屋檐，余气充足时翻滚一次，然后自动翻正；空中仍可转向。
- 下降时按速度计算制动距离，提前启动底部冷气喷口，缓冲路面或屋顶着陆。按住起飞仍可悬停，松开后进入着陆辅助。喷气消耗瓶内气体，空瓶不产生推力。
- 超过约 90 km/h 向前行驶时按 S / 手机「刹车」，车头双喷口向前喷出冷气，叠加减速并显示「前喷气制动」；低速/倒车不触发，同时按推进时优先制动。
- `tools/openracing/rooftop.test.ts` 在 30/60/120 Hz 验证 80/300/500 m 爬楼完整流程、500 m 坠落和有气/无气制动距离。

- 玩家车调用 `src/race/roadsterModel.ts`，与赛道模式、Roadster 2 v4 标准模型包保持同一几何来源。尾翼升降与角度由 `roadsterAero.ts` 统一计算，包含折叠连杆、端板和执行杆；高速巡航低角度展开，刹车时增加角度。灯组按 10 月 18 日照片细化。
  车轮、门、尾翼支杆、方向盘和刹车灯独立动画；展车状态在开动时自动关闭。
- 四个底部喷口、两个后喷口和侧向姿态喷气跟随车体。冷气使用短白雾、地面扬尘与淡化尾迹。
- 悬浮目标约为起飞点上方 3.5 m，保持油门不再导致车辆自动前翻。
  按 A / D 时车头和速度方向共同响应；松开手动俯仰/横滚后自动回正。
- X 横滚约 0.95 秒，消耗 60 L，不因一直按住而重复触发。翻滚为可控的车体视觉动作，
  不强行旋转物理碰撞体；接地时终止动作。
- 下落时近地喷气减小垂直冲击，落地时车身压缩后回弹；推进剂耗尽时不会凭空补充升力。
  修复了回正四元数的输出与目标互相覆盖问题；首次接地对齐支撑面，压缩行程限制到 6.5 cm，避免车头/车尾保持倾斜插入地面。
- 推进剂游戏容量 600 L，持续悬浮消耗 48 L/s，主推进 26 L/s；空中微推、姿态和着陆缓冲另有消耗。
  落地停止喷气后恢复。气瓶显示剩余百分比，速度表外圈也显示剩余量。
- 与现有赛道 Roadster 配置统一，水平车速上限为 370.15 km/h，推进也不突破上限。
  此数值沿用项目设定，不是对实际飞行车型极速的验证。

## 来源与边界

街道地图、路网、车流、任务、音效与基础物理来自本项目用户提供的 `hupiao/` 源码，
整合代码位于 `src/openracing/`；原始输入目录未修改。
车型使用本项目按用户视频重建的 Roadster 2 模型，替换原街道车型。
城市为程序化概括布局，建筑、车流和贴图不代表实景测绘；吸附、悬浮、空中翻滚为街机玩法。
用户提供的原始视频和源码压缩包未打入线上静态资源。

## 开发与验证

```sh
npm run dev
npm run test:openracing
npm run test:car
npm run test:worker
npm run build
npm run preview -- --port 5178
```

开放街道 51 项测试覆盖碰撞、贴墙上楼顶、飞越河道、车流、目标/连击，以及
30/60/120 Hz 悬浮稳定、空中转向、翻滚单次触发、推进剂、着陆缓冲、展车和限速。
新增倾斜落地轮胎离地检查、两岸各五种低油量过江操作、辅助主动退出/耗尽及游轮航线连续性/动态碰撞检查。
浏览器检查使用 `tools/check-openracing.cjs`（需要 Playwright 和 Edge；可用 `PLAYWRIGHT_MODULE` 指定模块路径，
`BASE_URL` 默认 `http://127.0.0.1:5178`）。检查共享车型、起降、翻滚、暂停、三个手机尺寸及真实多点触控。

`?q=low` 强制轻量模式，`?q=high` 强制高画质；默认手机轻量、桌面高画质。
`?manual` 供自动化逐帧验证使用。调试接口是 `window.openracing`；
`sim()` 仅推进物理，截图应再调用 `frame()` 更新动画。浏览器测试截图输出在被忽略的 `checks/openracing/`。
街道计时成绩存入独立键 `openracing.roadster-v3.bestTrial`，与赛道成绩分开。
