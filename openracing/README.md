# 开放街道 openracing

访问 `/openracing/`，或从赛道主菜单点击「开放街道」。页面右上角「赛道」返回原竞速模式。
共享依赖和车型代码由 Vite 多入口构建输出，两个模式按需加载各自场景。

## 玩法与操作

从南京东路出发，探索外滩和陆家嘴，完成拍照点、计时赛和美食探索；漂移、滞空、贴墙、擦车积累连击。
车流遵循路网和信号灯，碰撞会打断连击。落水后自动回到安全点，也可主动复位。

| 输入 | 功能 |
| --- | --- |
| W / S | 地面油门 / 制动倒车；空中微推 / 减速 |
| A / D | 地面转向；空中转向和速度方向辅助 |
| E（或 J） | 点按起跳，持续按住定高悬浮；松开下降 |
| Shift | 后部冷气推进，地面与空中均可使用 |
| X | 停车开蝶翼门/尾翼展车；离地足够高时单次横滚 |
| F | 切换底部风扇吸附，贴墙/倒挂，约 7 秒过热 |
| 空格 | 手刹漂移；空中配合 A / D 手动横滚 |
| I / K | 空中手动俯仰；松开后自动稳定 |
| R | 原地扶正复位 |
| C / M / H（Esc） | 切换相机 / 静音 / 暂停帮助 |

手机提供两侧驾驶按钮，可同时按加速与起飞；失去焦点或暂停时释放按键，避免持续加速。
手柄左摇杆转向/俯仰，RT/LT 油门/制动，A 悬浮，RB 推进，B 展车/翻滚，X 手刹，Y 吸附，Back 复位，Start 换视角。

## 模型与腾空

- 玩家车调用 `src/race/roadsterModel.ts`，与赛道模式、Roadster 2 v3 标准模型包保持同一几何来源。
  车轮、门、尾翼支杆、方向盘和刹车灯独立动画；展车状态在开动时自动关闭。
- 四个底部喷口、两个后喷口和侧向姿态喷气跟随车体。冷气使用短白雾、地面扬尘与淡化尾迹。
- 悬浮目标约为起飞点上方 3.5 m，保持油门不再导致车辆自动前翻。
  按 A / D 时车头和速度方向共同响应；松开手动俯仰/横滚后自动回正。
- X 横滚约 0.95 秒，消耗 60 L，不因一直按住而重复触发。翻滚为可控的车体视觉动作，
  不强行旋转物理碰撞体；接地时终止动作。
- 下落时近地喷气减小垂直冲击，落地时车身压缩后回弹；推进剂耗尽时不会凭空补充升力。
- 推进剂游戏容量 600 L，持续悬浮消耗 75 L/s，主推进 40 L/s；空中微推、姿态和着陆缓冲另有消耗。
  落地停止喷气后恢复。气瓶显示剩余百分比，速度表外圈也显示剩余量。
- 与现有赛道 Roadster 配置统一，水平车速上限为 370.15 km/h，推进也不突破上限。
  此数值沿用项目设定，不是对实际飞行车型极速的验证。

## 来源与边界

街道地图、路网、车流、任务、音效与基础物理来自本项目用户提供的 `hupiao/` 源码，
整合代码位于 `src/openracing/`；原始输入目录未修改。
车型使用本项目按用户视频重建的 Roadster 2 模型，替换原街道车型。
城市为程序化概括布局，建筑、车流和贴图不代表实景测绘；吸附、悬浮、空中翻滚为街机玩法。
用户提供的原始视频和源码压缩包未打入线上静态资源。

## 开发与验证

```sh
npm run dev
npm run test:openracing
npm run test:car
npm run test:worker
npm run build
npm run preview -- --port 5178
```

开放街道 36 项测试覆盖碰撞、贴墙上楼顶、飞越河道、车流、目标/连击，以及
30/60/120 Hz 悬浮稳定、空中转向、翻滚单次触发、推进剂、着陆缓冲、展车和限速。
浏览器检查使用 `tools/check-openracing.cjs`（需要 Playwright 和 Edge；可用 `PLAYWRIGHT_MODULE` 指定模块路径，
`BASE_URL` 默认 `http://127.0.0.1:5178`）。检查共享车型、起降、翻滚、暂停、三个手机尺寸及真实多点触控。

`?q=low` 强制轻量模式，`?q=high` 强制高画质；默认手机轻量、桌面高画质。
`?manual` 供自动化逐帧验证使用。调试接口是 `window.openracing`；
`sim()` 仅推进物理，截图应再调用 `frame()` 更新动画。浏览器测试截图输出在被忽略的 `checks/openracing/`。
街道计时成绩存入独立键 `openracing.roadster-v3.bestTrial`，与赛道成绩分开。
